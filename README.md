# Club desde Cero ⚽

Un club de fútbol creado entre todos. Cada seguidor de [@club.desdecero](https://www.instagram.com/club.desdecero/) es un socio y cada día se vota algo nuevo del club.

- `index.html` — la web (estática, se publica con GitHub Pages)
- `supabase.sql` — la base de datos (se ejecuta una vez en Supabase → SQL Editor)

La clave de Supabase que hay en `index.html` es la **publicable**, pensada para ir en la web. La clave secreta nunca va en este repositorio.
